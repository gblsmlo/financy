# Task 006 — Páginas e features do front-end

## Objetivo

Todas as páginas e os dois modais implementados, fiéis ao Figma, cobrindo os 10 requisitos
funcionais compartilhados com o back-end (FR-01 a FR-10).

## Critérios de aceite

- [ ] Tela de login e tela de cadastro.
- [ ] Dashboard com transações e categorias do usuário logado.
- [ ] Modal (dialog) de criar/editar transação, com React Hook Form + Zod.
- [ ] Modal (dialog) de criar/editar categoria, com React Hook Form + Zod.
- [ ] Ações de deletar transação e categoria (com confirmação).
- [ ] Listagem de transações e categorias via React Query, com loading/erro/empty state.
- [ ] Erros de API mapeados pros campos do formulário quando aplicável (ex.: e-mail já
      cadastrado).
- [ ] Revisão pixel a pixel contra o Figma nas páginas obrigatórias.
